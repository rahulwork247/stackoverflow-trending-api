# StackOverflow Trending API

This repository provides a free, public JSON endpoint with the most‑viewed StackOverflow questions for the default tag set (`python`).

The JSON file is generated daily by a GitHub Actions workflow and served via GitHub Pages at:

```
https://rahulwork247.github.io/stackoverflow-trending-api/trending.json
```

Feel free to use it in your tools! If you find it helpful, consider supporting the project via GitHub Sponsors or Buy Me a Coffee.
